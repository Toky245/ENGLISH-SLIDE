01 Introduction

Why passwords still matter.

A password is the first — and often only — line of defense for an online account.

  • Weak or reused passwords are the main entry vector for attackers.
  • Most users don't know their password has already leaked.
  • One reused password = many accounts compromised at once.
✓ A strong password
  • 14+ characters long
  • Mix of upper, lower, digits, symbols
  • Unique for every account
  • Stored in a password manager
✗ A weak / reused one
  • Short (< 8 characters)
  • Common words: password, 123456…
  • Based on name or birthday
  • Used on multiple sites at once
81%
of data breaches involve a weak or stolen password. Verizon — DBIR 2024
700M+
compromised passwords indexed worldwide. HaveIBeenPwned — Troy Hunt
65%
of users reuse the same password on several accounts. Google × Harris Poll, 2019
Sources: Verizon Data Breach Investigations Report 2024 · haveibeenpwned.com · Google & Harris Poll — Online Security Survey, 2019.

03 How it works

The k-Anonymity trick.

Your password never leaves your machine. Here's the step-by-step + the why behind it.

① Local hashing

Browser hashes the password with SHA-1, locally.

pwd → 5BAA61E4C9B93F3F0682250B…

② Prefix only

Only 5 characters of the hash leave your machine.

5BAA6

③ Local match

HIBP returns all hashes for that prefix → compared locally.

match? → exposed / safe ✓
Key technical choices
SHA-1 used only as a lookup key for HIBP — never as a security primitive.
k-Anonymity only the 5-char prefix of the hash leaves your browser.
HIBP Troy Hunt's DB — 700M+ compromised passwords indexed.
100 % client-side no password ever transmitted, stored or logged.

04.1 Attack #1

Dictionary Attack.

lol your pwd is in my list
  • dataset 10,000 commons
  • speed instant
  • detects predictable

How it works

The simulator loads a list of the 10,000 most commonly used passwords — gathered from major breaches — and checks whether the entered password matches one of them.

Why it matters

Attackers always try this first. A predictable password is cracked in milliseconds, no matter how complex it looks.

examples caught: 123456 password qwerty iloveyou admin
presented by RAHAJASON Audrey #4606
04.2 Attack #2

Rule-based Mutations.

i lov P@ssw0rd123 !!
  • method transformations
  • rules leet · suffix · case
  • detects "smart" weak pwds

How it works

Common base words are transformed with predictable rules: replacing letters with numbers, appending suffixes, switching case.

password→P@ssw0rd
password→password123
admin→Adm1n!
summer→Summer2024

Why it matters

Users believe these tricks make their password unique. They don't — attackers automate exactly these mutations.

04.3 Attack #3

Brute Force Estimation.

how long till u crack? do the math.
  • method math model
  • baseline modern GPU
  • output time-to-crack

How it works

We compute the keyspace (charset size ^ password length) and divide by the number of guesses a modern GPU can perform per second.

lengthcharsettime to crack
8lowercase~ 2 seconds
10alphanumeric~ 1 hour
14full ASCII~ 50 million years

Why it matters

Length beats complexity. Adding one character grows the search space exponentially.
